一、最推荐：基于你现有数据的“内生扩充”（优先级最高）
===========================

这是最现实、最稳的方案。

1️⃣ 行为序列增强（Sequence Augmentation）
---------------------------------

针对你的核心数据（行为轨迹），可以做：

### 方法A：子序列切片（强烈推荐）

把一条长序列拆成多个训练样本：

```
原序列：A → B → C → D → E

可生成：
A → B
A → B → C
B → C → D
C → D → E
```

👉 直接把500条变成几千条是常规操作

* * *

### 方法B：滑动窗口（时间序列标准做法）

定义窗口大小 k：

```
window=3
A B C D E → (A,B,C), (B,C,D), (C,D,E)
```

适合：

*   RNN / Transformer
*   马尔可夫建模

* * *

### 方法C：随机mask / dropout行为

模拟用户不完整行为：

```
A → B → C → D
→ A → [MASK] → C → D
```

👉 提升模型鲁棒性（类似BERT思想）

* * *

### 方法D：行为替换（语义级增强）

例如：

*   “点击商品A” → “点击同类商品B”
*   “浏览奶茶店” → “浏览咖啡店”

前提：需要构建**item embedding / 类目体系**

* * *

2️⃣ 用户扩充（User-level Augmentation）
---------------------------------

你现在只有200用户 → 非常危险

### 方法A：用户画像扰动

*   年龄 ±2

👉 可以扩成 3–5倍用户规模

* * *

### 方法B：用户行为拼接（关键技巧）

把多个用户的行为片段拼接：

```
User1: A B C

→ 新用户：A B C D E

        '是否用券': ['sum', 'count']

    # 拟合Beta分布
    mean = np.mean(coupon_rate)
    var = np.var(coupon_rate)

    alpha = mean * (mean*(1-mean)/var - 1)
    beta = (1-mean) * (mean*(1-mean)/var - 1)

    return alpha, beta
```

def compute_user_coupon_matrix(users, coupons, time_factor=1.0):
    rows = []

    for _, u in users.iterrows():
        V = u['value']
        A = u['activity']
        S = u['sensitivity']

        beta = compute_beta_hetero(V, A, time_factor)

        for c in coupons:
            coupon_value = c['value']

            delta = compute_delta_hetero(beta, S, coupon_value, V)

            P0 = beta
            P1 = min(beta + delta, 1.0)

            GTV0 = P0 * V
            GTV1 = P1 * (V + coupon_value * 0.3)  # 假设30%带动客单提升

            delta_gtv = GTV1 - GTV0
            cost = P1 * coupon_value

            rows.append({
                "user_id": u['user_id'],
                "coupon_id": c['id'],
                "value": delta_gtv,
                "cost": cost
            })

    return pd.DataFrame(rows)

def greedy_optimization(matrix, budget):
    matrix = matrix.copy()
    matrix['roi'] = matrix['value'] / (matrix['cost'] + 1e-6)

    # 每个用户只选一个券
    matrix = matrix.sort_values('roi', ascending=False)

    selected_users = set()
    total_cost = 0
    result = []

    for _, row in matrix.iterrows():
        uid = row['user_id']

        if uid in selected_users:
            continue

        if total_cost + row['cost'] > budget:
            continue

        selected_users.add(uid)
        total_cost += row['cost']
        result.append(row)

    return pd.DataFrame(result)
```

class BanditAgent:
    def __init__(self, n_actions):
        self.counts = np.zeros(n_actions)
        self.values = np.zeros(n_actions)

    def select_action(self):
        # UCB
        total = np.sum(self.counts) + 1
        ucb = self.values + np.sqrt(2 * np.log(total) / (self.counts + 1e-6))
        return np.argmax(ucb)

    def update(self, action, reward):
        self.counts[action] += 1
        n = self.counts[action]
        value = self.values[action]
        self.values[action] = (n-1)/n * value + reward/n
```

def extract_funnel_probs(sequences):
    counts = {
        ("view","click"):0,
        ("click","cart"):0,
        ("cart","purchase"):0
    }

    base = {
        "view":0,
        "click":0,
        "cart":0
    }

    for seq in sequences:
        for i in range(len(seq)-1):
            a, b = seq[i], seq[i+1]
            if (a,b) in counts:
                counts[(a,b)] += 1
            if a in base:
                base[a] += 1

    p1 = counts[("view","click")] / max(base["view"],1)
    p2 = counts[("click","cart")] / max(base["click"],1)
    p3 = counts[("cart","purchase")] / max(base["cart"],1)

def simulate_funnel(user, coupon_value=None, time_factor=1.0):
    V = user['value']
    A = user['activity']
    S = user['sensitivity']

    # ===== Funnel各层 =====
    p1 = sigmoid(-1 + 0.3 * np.log(V) + 0.5 * time_factor)
    p2 = sigmoid(-1 + 0.8 * A)
    p3 = sigmoid(-2 + 1.2 * S + 0.3 * np.log(V))

    if coupon_value is not None:

    P = p1 * p2 * p3
