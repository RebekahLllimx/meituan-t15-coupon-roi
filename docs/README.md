# Documentation

The public project maintains two documents:

1. [Engineering Design](ENGINEERING_DESIGN.md) defines the software boundary, architecture, interfaces, testing strategy, and technical decisions.
2. [Final Technical Report](FINAL_REPORT.md) records the current experiment, reproducible benchmark, results, and evidence limits.

The root [README](../README.md) is the entry point for installation and execution. Historical drafts and generated report assets are deliberately not part of the maintained documentation set.
