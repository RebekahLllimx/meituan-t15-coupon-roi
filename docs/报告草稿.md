# 下午茶补贴策略的半合成仿真与优化研究

## 一、背景介绍与研究问题

### 1.1 研究背景

在平台补贴策略设计中，最常见的方法是通过 A/B Test 对不同券策略进行在线实验。然而在下午茶这类典型长尾场景中，A/B Test 存在两个明显问题。

第一，实验周期长且存在真实流量损耗。若实验持续数周，则优策略在对照组中的增量无法被即时获取，劣策略在实验组中又会带来真实损失。  
第二，长尾场景样本稀疏，难以满足假设检验所需的最小样本量，导致策略优劣难以被稳定识别。

因此，本项目研究的问题不是“如何直接用小样本训练一个预测模型”，而是：

> 如何在数据结构不完整、样本规模有限的条件下，构建一个能够支持下午茶场景反事实评估与补贴优化的半合成仿真系统。

### 1.2 核心研究问题

本文聚焦以下三个问题：

1. 如何从割裂的原始数据中提取可用于建模的结构与约束？
2. 如何在缺乏完整闭环样本的情况下构建合理的用户决策仿真环境？
3. 如何在预算约束下输出兼顾收益与探索的个体化发券策略？

### 1.3 研究思路

本文采用“数据约束 + 分布拟合 + 半合成仿真 + 因果校正 + Bandit 优化”的整体框架。

其核心思想是：

> 用原始数据定义用户分布与行为结构，再在结构化环境中推导不同补贴策略的反事实结果，而非直接从小样本中学习因果效应。

整体系统架构可在正文中对应为图1“系统架构流程图”，用于先总览原始数据、半合成生成、因果仿真与 Bandit 优化之间的关系。

## 二、数据的说明与描述

### 2.1 数据来源

本项目使用三张脱敏业务数据表：

1. 用户画像表  
2. 神券订单数据样例  
3. 用户行为序列

其中：

- 用户画像表包含 200 个用户的静态画像字段；
- 订单表包含 950 条订单记录；
- 行为序列表包含 478 条行为记录，对应 8 个行为用户。

### 2.2 数据结构特征

当前数据并不能形成“行为 → 下单 → 用券 → 结果”的真实用户闭环，因此不适合直接用于监督学习或因果推断。三张表在当前系统中的角色被重新定义为：

- 订单表：用于拟合用户异质性分布与场景约束
- 行为序列：用于提取决策路径结构
- 用户画像：用于解释与生成约束

### 2.3 下午茶场景定义

为了避免将正餐、超市、泛生活服务误纳入目标场景，本文对下午茶场景采用以下约束：

1. 时间窗口限定在 14:00-17:00；
2. BU 主要保留饮品、甜点、水果、酒水茶饮；
3. POI 主要保留咖啡、奶茶、果切、蛋糕、西式点心等；
4. 对明显正餐、快餐、超市业态做排除；
5. 对订单金额做合理区间过滤，以强化下午茶消费特征。

## 三、模型的建立与评价

### 3.1 建模框架

本文模型分为五层：

1. 用户异质性分布拟合
2. Funnel 决策结构建模
3. 优惠券机制作用建模
4. 因果校正
5. Contextual Bandit 优化

### 3.2 用户异质性建模

从订单数据中提取三类核心变量：

- 用户价值 `V`
- 活跃度 `A`
- 价格敏感度 `S`

在基线设定下，三者的优先候选分别为：

- `V -> LogNormal`
- `A -> Gamma`
- `S -> Beta`

但在样本量不足、分布形状异常或拟合不稳定时，系统会自动退回到经验分布（Empirical）或规则生成（Rule-based），以保证仿真环境的稳健性优先于“分布形式上的最优拟合”。

由于当前下午茶场景过滤后订单样本较少，答辩时可以明确说明：本实验中自动选择器更偏向采用经验分布生成器，这是一个有意的稳健决策，而不是模型能力不足。

在此基础上，从真实画像表中有放回采样并加入静态约束，生成大规模虚拟用户池，作为仿真环境中的用户主体。

其中，`V/A/S` 的生成结果建议在正文中对应图5“生成用户 `V/A/S` 分布图”；用户在价值、敏感度、活跃度三维上的状态可对应图6“生成用户状态地图”。若答辩中需要解释为什么不是固定分布，也可补充图7“自动分布选择结果表”。

### 3.3 Funnel 结构建模

用户购买过程被建模为三阶段漏斗：

- `p1: view -> click`
- `p2: click -> cart`
- `p3: cart -> purchase`

行为序列数据仅用于估计全局 Funnel 结构，而不用于拟合真实个体参数。

自然转化率定义为：

`beta = p1 * p2 * p3`

该结构在正文中对应图8“下午茶场景 Funnel 结构图”，不同人群在各阶段的差异可对应图9“不同用户分层的 Funnel 阶段差异图”。

### 3.4 券作用机制

优惠券仅作用在最后一层购买阶段：

`p3_coupon = p3 + delta`

其中券增量函数定义为：

`delta = S * log(1 + coupon / V) * (1 - p3)`

这一设定体现了三个业务直觉：

1. 用户越价格敏感，补贴作用越强；
2. 券面额相对于用户价值越大，刺激越明显；
3. 当用户本来就几乎会购买时，券的增量作用应递减。

这一机制可用图10“候选券吸引力与客单 uplift 对比图”和图11“券增量概率随券面额变化图”配合展示。

### 3.5 GTV 与因果校正

无券和有券的期望 GTV 分别定义为：

- `GTV0 = P0 * V`
- `GTV1 = P1 * (V + uplift)`

同时，考虑到高自然转化用户本就更容易下单，本文引入因果校正：

`Delta_GTV_causal = (GTV1 - GTV0) * (1 - beta)`

因此，优化目标不再是简单增量 GTV，而是更接近反事实意义的因果增量收益。

### 3.6 Contextual Bandit 优化

在优化阶段，本文定义：

- `state = (V, A, S)`
- `action = coupon`
- `reward = Delta_GTV_causal`

并引入：

- `uncertainty = 1 / sqrt(1 + exposure)`
- `value_ucb = value + alpha * uncertainty`

在预算约束和单券型覆盖上限约束下，根据 `value_ucb / cost` 排序发券，实现“收益最大化 + 探索保留”的平衡。

### 3.7 模型评价

建议从以下四个维度评价模型：

1. 校准性  
比较半合成用户与真实场景订单在平均客单价、券使用率等统计量上的一致性。

2. 机制合理性  
检查是否满足：
- 券面额越大，转化率越高；
- 用户价值越高，基础购买能力越强；
- 价格敏感用户更易受券刺激。

3. 优化有效性  
比较：
- 不发券
- 统一发某类券
- Bandit 优化策略

4. 稳健性  
通过敏感性分析考察：
- 分布参数变化时 ROI 是否稳定；
- Funnel 参数变化时最优策略是否显著改变。

## 四、商业应用与总结

### 4.1 商业应用价值

该系统适合用于：

1. 长尾场景策略预演  
在真实 A/B Test 之前，先用半合成环境筛选候选券策略。

2. 预算约束下的个体化发券  
结合用户状态与不确定性，在有限补贴预算中优先覆盖高收益用户。

3. 低样本业务的策略探索  
对于真实流量不足、实验周期过长的细分场景，提供低成本的策略比较工具。

### 4.2 系统优势

相较于直接监督学习，本文方案的优势在于：

1. 不依赖完整闭环样本；
2. 保留了用户行为路径的可解释性；
3. 可将因果约束直接嵌入收益函数；
4. 支持探索与利用并存的动态优化；
5. 可继续接入更多先验变量，如天气、节假日、POI 属性等。

### 4.3 局限性

本文仍存在以下限制：

1. 场景约束与机制函数仍依赖业务假设；
2. 行为序列样本较少，Funnel 结构仍偏粗粒度；
3. 当前 Bandit 仍是轻量实现，尚未扩展为完整 Bayesian Bandit；
4. 尚未引入天气、节假日等外部环境变量。

### 4.4 结论

本文在数据割裂、小样本和长尾场景约束下，构建了一套以“分布拟合 + Funnel 仿真 + 因果校正 + Contextual Bandit”为核心的半合成补贴优化系统。该系统并不追求从有限数据中直接恢复真实因果，而是通过结构化建模构建一个可解释、可优化、可扩展的决策环境，从而为下午茶场景的补贴策略评估和个体化发券提供一种更稳健的工程实现路径。
